# 写作 Writing

面向直播场景的绿色免安装码字工具：**一个 exe，双击即用**，无需安装、无运行库要求（Windows 10/11 自带 .NET Framework 4.8）。

**发布版**：`Release\写作.exe`（约 195 KB）

## 功能清单（对应需求）

| # | 需求 | 实现 |
|---|------|------|
| 1 | Windows 平台、exe 直接打开 | ✓ 单 exe，双击运行 |
| 2 | 绿色免安装、只有一个 exe | ✓ 无任何安装步骤；配置可选生成在 exe 旁 |
| 3 | 选择本地文件夹及里面的文件 | ✓ 「打开文件夹」以**多层级目录树**浏览本地目录：逐层懒加载展开任意层级子文件夹，双击 txt 打开（**外部改动实时刷新**）；选中某个目录后「新建文档」就在该目录创建；也支持打开文件、拖拽进窗口（多个文件各开一个标签） |
| 4 | txt 文档读取 | ✓ 自动识别 UTF-8（含/不含 BOM）、UTF-16、GBK/GB18030 编码 |
| 5 | 码字面板 | ✓ 中央大编辑区，行距 1.7 倍，护眼排版 |
| 6 | 字体大小调整 | ✓ 工具栏 A-/A+（12~48），Ctrl+鼠标滚轮、Ctrl + / - 也可调节 |
| 7 | 自动缩进 | ✓ 回车自动换行并空两格（两个全角空格）；工具栏可开关；Shift+Enter 换行不缩进；采用“不拦截回车、换行后补缩进”的实现，对各类输入法（组词回车）零干扰 |
| 8 | 码字速度、3 秒取一次样 | ✓ 状态栏实时显示「字/分」，每 3 秒采样一次并做平滑估值（显示 12、64 这类数值），停止输入约 9 秒后归零 |
| 9 | 当前文档已码多少字 | ✓ 「文档字数」（不含空白、含标点）+「累计已码」（应用生命周期累计的实际键入字符数，切换文档不清零；选中替换、删除重打都计入） |
| 10 | 净字数（剔除所有标点） | ✓ 「净字数」剔除中英文标点与常用符号 |
| 11 | 码字背景替换 | ✓ 默认白 / 奶绿（豆沙绿 #C7EDCC）/ 天蓝（#CCE8FF），一键切换并记忆 |
| 12 | 多文档同开 | ✓ 编辑区上方为**文档标签栏**，可同时打开多个 txt 并在标签间切换；每个标签独立保存编码、光标与滚动位置 |

## 界面

极简**浅色**风格（白色外框 + 浅灰页面），控件模板集中在 `Writing\Theme.cs`（纯代码 WPF 通过 XamlReader 解析）：

- **配色**：工具栏 / 侧栏纯白 `#FFFFFF`、页面底 `#F6F7F9`、分隔线 `#E9EBEF`、强调色 `#2F6FEB`、悬停 `#F2F4F7`
- **工具栏**：无边框幽灵按钮，按功能分组、细线分隔；开关类按钮选中后为淡蓝底（`#EBF1FD`）＋蓝字
- **背景切换**：三个圆形色块（默认白 / 奶绿 / 天蓝），选中项带蓝色高亮环
- **目录面板**：白色侧栏，文件夹半粗体、txt 文件浅灰；选中项为淡蓝圆角胶囊；**自动隐藏 `.git` 目录**
- **目录树 Git 状态**：文件按 git 状态着色并右对齐显示字母——`M` 已修改（`#895503`）、`U` 未跟踪 / `A` 新增（`#587C0C`）、`D` 删除（`#AD0707`）；存在改动的目录名后显示灰色圆点 ●（配色取自 VS Code Light，在白底上清晰可读）
- **编辑区**：浅灰页面上浮起的纸张卡片（白/奶绿/天蓝可选），内边距 40/32，行距 1.7 倍
- **文档标签栏**：编辑区上方一条白色标签栏，当前标签为淡蓝底（`#EBF1FD`）＋蓝字＋蓝色下划线，右侧为 `+` 新建、`‹` `›` 切换与「共 N 个」计数；标签可用鼠标滚轮横向滚动
- **滚动条（编辑区）**：自绘指示条——系统滚动条在长文本下滑块会被 WPF 的 Track 压缩到几个像素，因此改用自绘条：6px 圆角、半透明深色、**最小长度固定 40px**；可拖动、可点击轨道空白处跳转，滚动/输入/窗口缩放时实时跟随
- **滚动条（目录树等）**：细圆角半透明滑块，悬停与拖动时加深；无箭头按钮
- **下拉框 / 右键菜单 / 键盘统计面板**：统一浅色风格，键盘面板敲过的键高亮为淡蓝底＋蓝字

## 多文档（标签页）

编辑区上方是文档标签栏，可同时打开多个 txt 文档：

- **打开**：双击目录树里的 txt、拖拽多个文件进窗口、或 `写作.exe a.txt b.txt` 都会各开一个标签；已打开的文档再次双击会直接切过去，不会重复打开也不重载
- **切换**：点标签、`Ctrl+Tab` / `Ctrl+Shift+Tab`、`Ctrl+1~8`，或用标签栏右侧的 `‹` `›`；每个标签记住自己的**光标位置、滚动位置与原编码**
- **关闭**：点标签上的 `×`、中键点标签、或 `Ctrl+W`；已命名的文档自动保存，未命名且有内容的会询问。关掉最后一个标签会自动补一个空白标签
- **状态显示**：当前标签蓝字加粗＋蓝色下划线，标题栏与工具栏显示 `(2/5) 文件名` 与 `●` 未保存标记
- **互不干扰**：切换文档会清空撤销栈（`Ctrl+Z` 不会把内容退回上一个文件）；标签数超出宽度时标签栏可横向滚动

## 附加功能

- **多层级目录树**：左侧「目录」面板按层级浏览本地文件夹，可展开任意层级的子目录（懒加载、不受层数限制）；「刷新」按钮重新扫描；双击文件打开；在树外打开的文件若位于当前目录树内会自动逐层展开定位选中
- **目录实时刷新**：程序监视着当前目录树（含所有子目录），外部新增／删除／改名 txt 或文件夹后**约 0.2 秒内自动出现在目录树里**，不用再点「刷新」；只重扫发生变化的那一层，展开状态与选中项保持不动。已打开的文档若被外部程序改写且本地没有未保存改动，会自动重新载入并在状态栏提示；源文件被删除时会提示（内容仍保留在标签里）
- **目录树状态记忆**：记住你选择的目录树根、**展开的多层目录**与**当前选中的目录**，下次启动原样恢复；打开/切换文件不会再把这个记忆覆盖成「上次编辑文件所在的目录」（打开目录树以外的文件只在本次会话内临时切换根目录）
- **文件重命名**：选中目录树中的 txt 后按 F2（或右键 → 重命名），节点变为输入框直接改名，回车确认、Esc 取消；重命名当前打开的文件时窗口标题同步更新
- **新建文档（就地命名）**：点击「新建文档」后，目录树中立即出现处于重命名样式的新文件节点，输入文件名回车即创建并打开，目录实时更新
- **键盘统计面板**：工具栏「键盘统计」打开悬浮面板，实时显示每个按键的敲击次数（全局键盘钩子按**物理按键**统计，不受输入法影响；仅统计本软件在前台时）；与累计已码一样为**应用生命周期累计**，切换文档不清零，支持一键重置
- **窗口大小记忆**：默认 1280×720（720P），手动拖拽调整大小后自动记忆，下次启动沿用（最大化时记住的是还原后的尺寸；超出屏幕会自动收进工作区）
- **命令行打开**：`写作.exe "文件夹或txt路径"` 启动时直接打开指定目录或文件；可一次给多个 txt，各自开一个标签
- **自动保存**：每 3 分钟自动保存一次，关闭窗口、**切换文档时也会自动保存**（剪切、删改等改动不会因切换文件而丢失；未命名且有内容的文档会询问）；关闭整个窗口时会保存**所有**标签
- **剪切更可靠**：Ctrl+X 由程序自行处理（先写剪贴板、再删除选区）。当系统剪贴板被其它程序占用导致写入失败时，WPF 内置 Cut 会跳过删除、表现为“剪切后原文还在”，本程序仍会完成剪切并在状态栏提示（Ctrl+Z 可还原）
- **撤销隔离**：切换文档会清空撤销栈，Ctrl+Z 只作用于当前文档，不会把内容回退成上一个文件
- **新建文档**：在当前选中的目录内就地命名创建新 txt，创建后自动打开
- **置顶**：工具栏「置顶」开关，方便直播时窗口盖在其他软件上
- **目录**：可折叠左侧文件面板，给码字区更大空间
- **时钟**：状态栏实时显示当前时间
- **编码保持**：按打开时的原编码保存（GBK 文件存回 GBK），新建文件存 UTF-8

## Git 管理

工具栏「Git」打开管理面板。需要本机已安装 [Git for Windows](https://git-scm.com)（程序会自动从 PATH 与常见安装目录查找 `git.exe`）。

- **多仓库**：添加任意本地 git 仓库（自动校验 `.git`），仓库列表保存在配置里；「在目录树中打开」可把该仓库直接设为目录树根
- **状态一览**：当前分支、变更文件数、领先/落后提交、最近一次提交、远端地址
- **更改列表**：实时列出工作区改动，带 VS Code 风格的状态字母与颜色（M / U / A / D）
- **提交历史（更新列表）**：列出最近 40 条提交（提交说明、作者、日期），每次刷新或提交后自动更新
- **分支**：列出全部本地分支并一键切换（`git checkout`）
- **拉取**：`git pull --ff-only`；若当前打开的文档位于该仓库内，拉取成功后自动重新载入编辑器
- **提交 / 提交并推送**：`git add -A` → `git commit -F <临时文件>`（支持中文与多行提交说明）→ `git push`；首次推送没有上游分支时自动改用 `push -u origin <分支>`
- **Personal access token（PAT）管理**：
  - 「已保存令牌」下拉列出所有已存令牌（显示为 `主机 · 用户名`），**选中即自动填入**主机、用户名、令牌三个输入框
  - 「确认（添加/更新令牌）」保存当前输入；「删除令牌」从配置与下拉列表中移除（删除后不再出现在选项里，相关仓库的绑定也一并清除）
  - **自动载入规则**（按优先级）：
    1. 该仓库上次使用的令牌 —— 进入仓库即自动载入，并在下方提示「已自动载入该仓库上次使用的令牌」
    2. 如果只保存了一个令牌 —— 任何仓库都默认载入它
    3. 按远端主机匹配 —— 例如远端是 `https://github.com/...` 时自动选用已保存的 `github.com` 令牌
    4. 以上都没有 —— 清空用户/令牌输入框（主机名仍自动填好），提示该仓库尚未绑定令牌
  - **令牌 ↔ 仓库绑定记忆**：在某个仓库中手动选择或保存令牌后，该绑定即被记住（例：仓库 A 用 a 令牌、仓库 B 改用 b 令牌，下次进入各自自动载入对应令牌）；绑定随令牌删除自动清理
  - 令牌使用 **Windows DPAPI（当前用户）加密**后写入配置文件，**绝不明文保存**（换机器需重新填写）
  - 仅对 `https://` 远端生效，通过 `http.extraheader` 传给 git，不会写入仓库的 `.git/config`；`git@` / `ssh://` 远端自动走系统 SSH 密钥
- **执行输出**：每条命令与 git 的原始输出实时显示在面板日志区，中文文件名不会被转义成八进制

## 统计口径

- **文档字数**：当前文档总字符数（不含空格、换行等空白，含标点）
- **净字数**：在总字数基础上再剔除中英文标点与常用符号（，。！？、""''《》—… 及半角 ,.!? 等）
- **累计已码**：自软件启动以来**实际键入**的字符数（应用生命周期累计，切换文档不清零；选中文字后直接输入替换、删除后重打都计入；粘贴不计入）
- **码字速度**：每 3 秒采样一次最近 3 秒的键入量，与历史值指数平滑后估值为字/分（可出现 12、64 等任意数值）；停止输入约 9 秒后归零

## 绿色说明

- 整个软件就是 `写作.exe` 一个文件，复制到 U 盘/任意目录即可使用，**exe 同目录不会再产生任何文件**
- 配置文件位于 **Windows 通用配置目录**下、用独立文件夹包裹：

  ```
  %APPDATA%\写作\Writing.ini
  （例如 C:\Users\你的用户名\AppData\Roaming\写作\Writing.ini）
  ```

- 保存内容：字号、自动缩进开关、背景色、窗口大小、目录树状态（根目录／展开层级／选中目录）、Git 仓库列表、**DPAPI 加密的访问令牌**及令牌↔仓库绑定
- **旧版本升级**：会自动迁移到新位置并删除旧文件（设置与令牌全部保留）——依次识别 `%APPDATA%\写作\LiveTyperSettings.ini`（旧文件名）、`%APPDATA%\码字直播助手\`（旧目录）、exe 同目录的 `LiveTyperSettings.ini`（更早的绿色版）
- 万一 `%APPDATA%` 不可写（极少见），才退回写到 exe 同目录
- 不写注册表、不装服务、不留后台进程

- Windows 7 SP1 及以上（推荐 Windows 10/11），64 位系统
- .NET Framework 4.8（Windows 10/11 系统自带，无需安装）

## 目录结构

```
novelApp\
├─ Release\写作.exe    ← 发布版(单文件)
├─ Writing\             ← 源码(纯 C# 5 语法,WPF 纯代码,无 XAML)
│  ├─ Program.cs           入口
│  ├─ MainWindow.cs        主窗口与全部交互逻辑
│  ├─ Theme.cs             极简浅色主题(控件模板)
│  ├─ GitPanel.cs          Git 管理面板(多仓库/分支/提交推送/PAT)
│  ├─ TextStats.cs         字数/净字数统计

│  ├─ Settings.cs          配置读写(存于 %APPDATA%\写作\，含旧版自动迁移)
│  ├─ Test.cs              逻辑自测(控制台,可选)
│  ├─ app.manifest         高 DPI / 系统兼容清单
│  └─ app.ico              图标
└─ build.ps1               ← 一键重新构建脚本
```

## 重新构建

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

使用系统自带 `csc.exe` 编译，**无需安装 .NET SDK、无需联网下载任何依赖**。
